# Colors

Every colour is a CSS variable in the `@theme` block of `src/index.css`, exposed as
Tailwind utilities. **Never hardcode a hex value** — use `bg-primary`, `text-body`,
`border-border` and friends.

All 31 tokens map 1:1 onto a Figma paint style, verified numerically: 31 exact
matches, zero mismatches, and no token on either side without a counterpart.

The hex column below is not hardcoded. It is read from each swatch's *computed*
`background-color`, so the table always reports what the token actually resolves
to — including through aliases like `--color-primary`.

## Things worth knowing

**The two ramps are not interchangeable at the same step.** Primary's default sits
at `600`, secondary's at `300`. Swapping `primary-600` for `secondary-600` will not
give you an equivalent colour.

**`secondary-600` is a dead zone — never put text on it.** It fails 4.5:1 against
*both* white (4.36) and black (3.79). There is no legible text colour for it.

**Text on primary:** white from `600` down; `text-black` on `100`–`500`.
**Text on secondary:** white only from `700` down; `text-black` on `100`–`500`.

**`black` is `#151515`, not `#000`.** The `@theme` declaration overrides Tailwind's
built-in, so `text-black` resolves to the design token. At `#151515` it is
visually indistinguishable from `body` (`#383636`) as running text — its actual
role is a UI neutral closing the grey ramp, which is why it is grouped there
rather than under Text.

**`grey-100` is `#444444`.** It was consolidated from two near-identical darks
(`#4F4F4F` and `#444444`) onto the value the Radio was designed against, which is
also the one in Figma's current `color/ui/*` namespace.
